# 一、标题生成的核心原则

对于马来西亚 TikTok Shop 居家日用品，标题的核心目标有四个：

1. 让用户一眼知道这是什么
2. 让平台识别核心关键词
3. 让用户理解主要功能和场景
4. 避免标题空泛、堆词、像机器拼出来

所以标题不要只写“神器”“爆款”“居家好物”，而要优先写清楚：

- 产品是什么
- 能解决什么问题
- 在什么场景下使用
- 适合什么人

---

# 二、推荐标题结构

建议优先使用以下结构：

`核心关键词 + 功能利益点 + 使用场景 + 目标人群/辅助属性`

例如：

- `Kitchen Sink Drain Basket for Easy Food Waste Filter and Storage`
- `Wall Mounted Mop Holder for Bathroom Kitchen Space Saving Storage`
- `Foldable Hanging Trash Bin for Kitchen Cabinet Easy Cleanup`

---

# 三、标题词库拆分

为了让 Claude / Codex 更稳定地生成标题，建议把标题拆成 6 类词来组合。

## 1. 核心产品词

这是标题里必须出现的主词，用来说明“这是什么”。

### 厨房类

- sink drain basket
- kitchen organizer
- fridge organizer
- storage box
- food container
- bag sealer
- dish rack
- spice rack
- hanging trash bin

### 清洁类

- cleaning brush
- gap brush
- mop holder
- broom holder
- cleaning tool
- scrub brush
- dust brush

### 收纳类

- storage rack
- organizer box
- wall rack
- drawer organizer
- foldable storage box
- under sink organizer
- bathroom organizer

---

## 2. 功能利益点词

这类词用于说明产品“能解决什么”。

- space saving
- easy cleaning
- easy storage
- anti clutter
- quick organize
- mess free
- no drill
- reusable
- portable
- multifunction
- strong hold
- easy install
- convenient
- durable

---

## 3. 场景词

场景词很重要，能让用户更快代入使用场景。

- for kitchen
- for bathroom
- for home
- for sink area
- for cabinet door
- for small space
- for apartment
- for fridge
- for countertop
- for daily use

---

## 4. 人群词

不是每个标题都要加人群词，但适当加入会更有转化表达。

- for home use
- for families
- for moms
- for renters
- for small apartments
- for kitchen lovers

---

## 5. 辅助属性词

用来进一步补充材质、安装方式、结构或使用特征。

- wall mounted
- self adhesive
- no punching
- foldable
- handheld
- compact
- clear
- hanging
- reusable
- waterproof

---

## 6. 热点辅助词

这类词不建议乱堆，但在适当时候可以用于增强吸引力。

- household essentials
- must have
- useful home tool
- kitchen helper
- home organizer
- daily use gadget

注意：  
热点辅助词尽量放在标题末尾或副标题逻辑里，不要把它当主词。

# 四、推荐标题公式

## 1. 基础稳妥型

适合绝大多数上架标题：

`核心产品词 + 功能利益点 + 场景词`

示例：

- `Sink Drain Basket Space Saving Kitchen Organizer`
- `Wall Mounted Mop Holder Easy Storage for Bathroom`

## 2. 转化表达型

适合功能比较明确、场景强的产品：

`核心产品词 + 功能利益点 + 场景词 + 辅助属性词`

示例：

- `Foldable Hanging Trash Bin Easy Cleanup for Kitchen Cabinet`
- `Self Adhesive Mop Holder Space Saving Rack for Bathroom`

## 3. 长尾覆盖型

适合竞争较大的类目：

`核心产品词 + 功能词 + 细分场景词 + 人群词`

示例：

- `Kitchen Sink Drain Basket for Food Waste Filter and Home Storage`
- `Bathroom Wall Mounted Mop Holder for Small Apartment Storage`

## 4. 轻热点型

适合 TikTok Shop 里需要稍微增强吸引力的标题：

`核心产品词 + 功能词 + 场景词 + 热点辅助词`

示例：

- `Kitchen Organizer Rack Space Saving Storage Household Essential`
- `Gap Cleaning Brush Easy Bathroom Cleaning Useful Home Tool`

# 六、标题生成时要避免的问题

## 1. 避免空泛标题

不推荐：

- amazing home product
- best household item
- viral home gadget

问题：

- 看不出是什么产品
- 搜索覆盖差
- 平台识别弱

## 2. 避免机械堆词

不推荐：

- kitchen organizer storage rack home kitchen organizer storage tool

问题：

- 可读性差
- 容易像机器拼接
- 转化弱

## 3. 避免把“热点词”放在主位

不推荐：

- viral tiktok must have kitchen thing

更推荐：

- `Kitchen Sink Organizer Basket Space Saving Household Essential`

## 4. 避免标题太短

如果标题太短，往往会丢掉：

- 场景词
- 功能词
- 搜索词

例如：

- `Mop Holder`

就远不如：

- `Wall Mounted Mop Holder for Bathroom Space Saving Storage`

# 七、标题长度建议

对这类居家日用品，建议标题长度控制在：

- `5 到 12 个英文词` 较稳妥

目标不是越长越好，而是：

- 主词清楚
- 功能明确
- 场景完整

# 八、给 Claude / Codex 的标题生成指令

你后面可以直接把这段补到调用里：

```md
请根据“核心产品词 + 功能利益点 + 使用场景 + 目标人群/辅助属性”的逻辑，为每个产品生成 3 个可上架标题。标题要自然、清晰、可搜索、可转化，避免空泛表达和机械堆词。
```

如果你想要更偏 TikTok Shop 的风格，可以加一句：

```md
标题优先体现产品用途、解决的问题和使用场景，而不是只强调“viral”或“must have”。
```

# 九、建议的实际使用方式

建议你后面这样用：

1. 先用关键词库找产品方向
2. 用评论判断词判断用户是否真想买
3. 用评分规则判断值不值得做
4. 最后用这份标题规则生成上架标题

这样生成的标题，会比单纯让模型“随便起个标题”稳定很多。
